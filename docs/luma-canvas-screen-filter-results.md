# luma Canvas 屏幕过滤：真实数据复测

本轮在本地 `luma集成` 分支的两个独立示例中复用 Canvas 微小 arc 和半设备像素连续重复命令过滤。默认 emap viewer/editor 仍是 Canvas。

## 测量条件

Apple M4，16 GiB，Chrome 153 headless，绘图区 1238×450 CSS px，DPR 1。只使用用户提供的完整五份 GeoJSON；PointLod 关闭。固定视图预热 4 帧、采样 12 帧；每个视图分别测原始 GPU 几何、过滤后的 GPU 几何和相同过滤命令的 Canvas 重绘。计时不使用 fast-nav 快照。rAF FPS 表示回调节奏，CPU 表示提交时间，不是 GPU 单独执行时间。

远景为完整范围倍率 exp(-3.2)，近景为 16×。小样本、单机、顺序测试，非独占机器，不保证其他机器或连续交互达到相同帧率。

## 显示与交互边界

微小 arc 阈值来自现有 Viewport：0.35 CSS px，按初始视图比例调整，包围盒宽高都严格小于阈值才省略。半像素规则来自 CanvasPainter：投影到设备像素后朝零截断至半像素，只跳过连续重复命令，不做 Douglas–Peucker、Visvalingam 或多级精度几何。它仍是显示近似，小弧可不显示、边界有像素级位移，不能宣称与未过滤图像逐像素一致。

过滤只影响背景线/面描边。原始 mapshaper dataset、面填充/洞、选择轮廓、原始编辑点、属性和 CRS 保持不变。屏幕投影与去重在 Worker 完成，精确缓存键包含平移/缩放/DPR/视口/源版本；平移也可能改变投影去重结果。连续操作使用快照，停止后筛选当前视图，不能拿固定视图暖重绘 FPS 当作每帧重新筛选的性能。

关闭两项过滤恢复原始 GPU 路径；Int32 溢出或屏幕缓存预算不足回退原始分块，不丢弃文件。默认测试中无回退块。已有点聚合是另外的开关，本轮测试关闭。

## 验证结果

191 项相关单元/回归通过，含实际 Canvas 命令序列对照、DPR/负坐标、阈值、塌缩路径、超界回退、缓存失效/过期 Worker 结果及原始编辑 Uniform 隔离。

五份完整文件×两 GPU 后端共 10 项过滤测试、30 个固定视图均通过：实际非空像素、暖重绘无新增几何上传、无缺失块、无捕获的页面/GPU 错误。SHA-256 前后一致，释放后跟踪 GPU 几何字节和数据 Worker 数归零。

39 项主浏览器套件首轮有 34 项通过、5 项编辑失败。新增状态行引起舞台位置变化与焦点滚动，已修复 preventScroll 并把编辑页过滤状态移到地图下方。修复后 WebGL2 编辑套件 6/6、WebGPU 编辑套件 6/6 均通过，分别覆盖五份原始文件的选择、移动、取消、撤销/重做、Worker 补丁、非空像素和释放。未将首轮失败描述为一次全绿测试。

root/examples 类型、公共类型契约、架构、测试布局、生产构建、中英文文档和示例验证通过；最后仅调整编辑页状态行位置后重新构建并通过两后端编辑回归。

## 使用

在已有 4187 服务打开 `/mapseekai/emap/examples/luma-benchmark/?gpu=webgl&pointLod=off`，WebGPU 改为 `gpu=webgpu`。默认启用两个新过滤开关。

点击“过滤后暖重绘压测”测当前固定视图已准备的过滤几何，不使用快照，准备耗时另列。点击“A/B 原始几何导航”仍测原始 GPU Buffer 逐帧导航，并排除新屏幕缓存；Canvas 自身绘制吸附仍存在。两种结果模式不可混算。

`screenFilter=off` 同时关闭两项；`smallArcs=off`、`halfPixel=off` 单独控制。

原始 JSON、截图和编辑结果保存在 `test-results/luma-screen-filter-evidence/`；实现说明 `docs/luma-canvas-screen-filter.md`。用户 4187 服务未关闭或重启；未提交、未推送、未发布。
