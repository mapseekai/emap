## 二、修复过程中确认并处理的关联问题

字段重命名的 undo 原先会误改只有目标字段、并未参与 do 的记录。现在记录实际修改索引，undo 仅恢复这些记录。

生产审计脚本原先受到安装镜像配置影响，无法获取有效审计结果。现在使用显式 registry 参数，默认官方 npm registry；可通过 EMAP_AUDIT_REGISTRY 单独配置，不修改全局安装镜像。网络或返回数据异常仍然失败，不使用 ignore-registry-errors 绕过。

允许列表原先可能放行同一已批准 ID 升级后的 critical 发现。现在仅 high 级别的已批准文档路径可临时允许；critical 不会被允许列表放行，并有专门的失败后修复测试。

浏览器示例目录测试原先将数量固定为 90，与工作区已有新增示例不一致。现在读取共享 manifest 并校验全部路由，而非改为另一个固定数量；没有删除现有新增示例。

已删除 map.ts 脱离对应方法的旧注释，并合并 AttributeOps 四处重复提交尾部。未删除公共 API 或运行时依赖，未进行大规模架构重写。
