# 描边格式分组、物理页绘制与精确失效

范围：正式 WebGL2/WebGPU 已加载矢量的渲染。GeoPackage 导入、拓扑、属性和业务索引未改动。
本轮接续 `luma-render-commands.md`；此前各轮报告保留各自当时的测量，不混用基线。

## 无损区分 XY 与高低位端点

屏幕过滤后的坐标仍以 high/low 表示。仅当某个有效线段两端的 low x/y 全部严格等于零，
才允许省掉这些零分量，使用 48 字节实例；任何非零 low 都继续使用 64 字节实例。
这不是将源 Float64 坐标降到 Float32，更不是半精度或重新量化。Shader 恢复已知的零 low，
保留原有连接计算和 MSAA 包络。深缩放、分数 DPR、人工保留的短退化弧都不丢低位。

同一不透明实线任务可以分别输出两种格式，避免少量带 low 的退化短弧使整个任务无法使用紧凑 XY。
两种格式的总字节一起检查，仍不超过原共享邻接格式的 1.125 倍；超出时保留原路径。
所有非零线段、邻接关系和端帽保留。原始数据不修改；复杂长线仍可能使用原格式。

## 只在单一不透明描边作用域内按页组织

物理页按格式隔离，48/64 字节步长、slice 起点、回收区间和两后端 VAO 均有独立检查。
命令编译器仅对同一颜色、线宽、屏幕基准的、不透明 MSAA 路径作用域按 Buffer 分组，
页内按物理区间排列，仍只合并真正连续且被选中的 slice。不跨越释放/未选中的空洞。

此条件下每个被覆盖样本写相同颜色，结果是相同颜色的覆盖并集；排序不改变父图层先后。
半透明线、虚线、箭头、点/图标、面填充等不使用这个重排条件。既有逐范围裁剪照常生效。
缓存保存原始成员和数值范围用于校验，仅编译结果允许上述重排，不是篡改 source 的顺序。

## 资源依赖失效

命令缓存维护 mesh 到作用域的反向依赖。淘汰一个 mesh 仅销毁引用它的计划，
其他 slice 即使位于同一物理页，也不会被连带清空。合并 span 的所有成员都登记依赖。
替换、淘汰、未使用作用域和设备销毁均解除依赖；128 作用域/32768 命令范围预算不变。

## 试验与测量口径

先试验了不增加 stride 的方向预计算，GPU 耗时没有稳定改善，因此未保留该修改。
单纯要求整个任务所有 low 都为零也没有明显收益：退化短弧的 0.1 像素保留会产生非零 low，
所以最终使用混合格式分组，并保留这些低位，而不是将它们截断为零。

本轮原始记录位于 `test-results/render-residency-round/`。
`before-*` 为新跑基线；`try-*` 是已撤回的方向试验；`xy-*` 是整任务判定的中间版本；
最终只用 `final-*` 与 `before-*` 的同路线对照，不混用中间版本的最佳数字。

Brandenburg 原文件全量导入，20 个表、5,028,831 条要素。原文件只读，脚本检查表行数及 SHA-256。
同机 Chrome、1280×852 CSS px、DPR=1、MSAA=4、同默认样式与 LOD。
每个后端运行一轮真实导航和固定 4/16/32/1× 视图；每视图十二次 CPU 提交和十二次 GPU timestamp 样本。
CPU 与 GPU 分开采集，GPU 样本使用异步完成屏障。不是连续输入 FPS，不把两者直接相加。
不清空文件系统缓存；不同时运行其他压测、构建或回归。导入时间不算本轮渲染收益。

256 MiB 几何软预算、512 MiB 工作集保护和页空闲容量统计均保留；没有新增源数据副本或 Worker。
反向依赖属于有界命令元数据，不计为 GPU Buffer；不能混淆条目大小、实际页容量和浏览器 RSS。

## 后续边界

长线和复杂连接的 GPU 计算、片元覆盖、活跃页碎片与新 LOD 冷几何仍有成本。
这次没有实现活跃页搬迁、多 Worker 并发或新的曲线/几何简化算法。文件导入仍留到最后。
未获外部任务写入授权，跟进仅记录在本地，不创建远程 issue。

### 画质检验

XY 记录恢复成完整64字节 high/low 记录的专项测试，两后端逐字节像素一致；
单一不透明作用域排序与关闭排序的专项对照也保持相同像素。

真实 Brandenburg 前后同一780×760地图区域（排除UI文本）的10组对照，每组8–11个边缘像素不同，
最大通道差51。混合布局使更多短路径能够采用已有连接预计算，仍可能产生稀疏MSAA边缘舍入差异；
不能把端点零分量省略的无损性扩大成整条新旧描边管线的逐像素等价声明。
结果见 `pixel-diffs.json`，保留原坐标、精确低位、MSAA、样式和全部非零段，不以隐藏差异通过验收。
