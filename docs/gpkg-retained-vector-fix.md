# GeoPackage：分块复用与导航收敛修复

## 范围

在 `f976ecb5` 和工作区已有的面／描边同步呈现改动之上修复；不回退同步呈现，不修改源文件。
本轮解决 4× 平移后重复填充资源耗尽工作集、失败请求掩盖排队状态、导航重复遍历和密集查询重复执行。
GPU 高密度描边的总吞吐问题仍存在，不能把本轮结果解释为所有视图达到 60 FPS。

## 实现

- 大数据实体填充与实线使用稳定源／过滤／样式成员。导航先选空间块，完整内部线块复用成员，仅边缘块重新检查视口；箭头、方向敏感虚线、任意过滤器和有序图标保留精确旧路径。
- 填充上传覆盖按实际源块判断：视口已经包含完整块时复用完整资源；局部覆盖比较视口与该块的交集，避免仅相机矩形变化就复制整批 GPU 数据。
- 合法的 `null` 候选查询结果同样缓存；源版本及 bounds 改变仍使查询失效。
- 同源、同版本、同内容、仍被选择的边缘块允许有界任务完成，避免每次移动都重启 Worker、丢失三角化缓存。
- 分别报告 `queued`、`building`、`failedEntries`、`blockedEntries`、`planningRequests`、`failedRequests`；`pending` 不再把失败请求后面的队列抹成零。单块失败不阻断独立后续块。
- 成员缓存限制在既有分区索引预算内，最多 128 个缓存键；空结果、过期任务、源释放与就地 ID 修改都参与生命周期检查。
- 碎片化描边裁剪最多保留八段，合并只增加保守误选、不删除可见实例；compact 仿射管线保持 hi/lo 算术并移除不可能执行的透视分支。

GPU 软预算仍为 256 MiB、硬上限 512 MiB；分区与成员缓存预算仍为 128 MiB。
没有提高 Worker 数量、减少源要素、隐藏边界、降低 MSAA 或改变源精度。

## 完整 GPKG 回归

Apple M4、16 GiB、Chrome 153.0.8010.53；地图 1280 × 852 CSS px、DPR=1。
完整 `brandenburg.gpkg`：1,048,797,184 字节、20 个矢量表、5,028,831 个要素。
路线：全图 → 4× → 24 次拖动（144 px）→ 16× → 返回全图；每个后端重复三轮。

| 后端 | 三次松手至确认就绪 | 采样工作集最高（含 external） | 错误／最终未完成 |
| --- | --- | ---: | --- |
| WebGL2 | 1,075 / 828 / 1,132 ms | 432.92 MiB | 0／0 |
| WebGPU | 800 / 776 / 1,076 ms | 445.55 MiB | 0／0 |

原故障路线在约 511 MiB 时分配失败并永久未完成；以上不是提高上限后的结果。
这些工作集数是采样的缓存记账，不是机器总内存或 GPU 总显存。六次回归销毁后 buffer、几何缓存、成员缓存和 Worker 均归零。

## 性能结果与边界

| 指标 | WebGL2 改前 → 改后 | WebGPU 改前 → 改后 |
| --- | --- | --- |
| 全图平移阶段墙钟 | 4,516.7 → 1,891.2 ms | 4,560.7 → 1,973.6 ms |
| 该平移阶段长任务数 | 22 → 0 | 12 → 0 |
| 4× 暖帧 CPU 提交 p50 | 17.6 → 14.6 ms | 9.9 → 3.5 ms |
| 4× 暖帧 GPU 时间 p50 | 35.51 → 37.57 ms | 48.30 → 50.14 ms |

平移采样前后都没有新建几何／上传；改后没有重新构建源成员列表，分别命中成员缓存 375／350 次。
旧平移采样在近远视图循环后执行，新采样从完整就绪全图开始；两者采用同样的 30 次鼠标移动和 profiler 配置，但缓存历史不同，墙钟变化不能单独归因于一行代码。
CPU 与 GPU 分开计时：暖 CPU 20 帧、GPU 12 个原生时间戳；不是端到端 FPS。没有显著 GPU 加速证据，4× GPU 中位数反而略高，因此不宣称 GPU 吞吐瓶颈已经消除。
回全图仍可能因预算淘汰而重建旧 LOD 几何；成员缓存并不等于无限 GPU 驻留，也不承诺所有缩放都零上传。预算无法容纳真实目标时仍明确报错，不会删减源数据。

原始报告、源码基线、CPU profiles、截图和回归脚本在 `test-results/gpkg-fix-20260925-1836/`。
`convergence.mjs` 是实际失败路线的三轮回归；`scripts/benchmark-geopackage-browser.mjs` 提供固定视图及原生 GPU 时间戳检查。输入文件哈希前后相同。
单元覆盖缓存失效、同色不同槽、空成员缓存上限、失败队列、边缘任务取消和保守范围合并；浏览器覆盖延迟交接、透明度、孔洞、共享边以及保留分块与原视口选择逐像素一致性。
本轮未验证 Windows、Firefox、Safari，也没有创建外部问题、提交或发布代码。
