属性驱动样式

classifyFeatures 分级烘焙

fill-color 表达式

加载一个含 polygon 图层的文件

分级烘焙:map.ops.classifyFeatures() 把颜色写入每条记录的 fill 字段(可 Ctrl+Z 撤销), fill 图层声明 styleSource: 'mapshaper' 后按烘焙字段渲染。 表达式:fill-color 直接接受 match / step / interpolate 子集,无需烘焙;非法表达式在 addLayer 时抛错。 字段为 null 的记录使用 null 色。
