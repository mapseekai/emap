Shapefile 查看器

GETTING STARTED / DATA / SHAPEFILE

在浏览器中加载 ZIP Shapefile；一个压缩包可包含多组数据，每个 .shp 将作为独立图层。你可以使用压缩包中的 .prj 自动识别坐标系，也可以在加载前指定 EPSG 或 Proj.4 坐标系覆盖它。

加载数据

每个图层需要一组同名 .shp、.shx、.dbf；.prj 可选。

支持 EPSG:NNNN 或以 +proj= 开头的 Proj.4 字符串。

等待选择 ZIP 文件。
