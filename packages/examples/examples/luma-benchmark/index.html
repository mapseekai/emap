测试口径与限制

这是独立 Painter 对照，不是默认地图引擎迁移。两种后端使用同一个 mapshaper dataset、相同视口/DPR、样式和轨迹；启用相同的保守空间裁剪，线面始终全精度；点在开启聚合时使用同一组原始代表点，关闭后绘制全量点，不使用 CSS 快照导航。A/B 按 Canvas → luma → luma → Canvas 顺序单独运行，每轮预热 12 帧、采样 60 帧。拖动/滚轮可手动比较。

CPU 指标测量 JS 绘制/提交，不代表 GPU 执行完成；rAF FPS 受刷新率、后台标签页和机器负载限制。显存数字仅为已跟踪几何及图像的估算，不含驱动、帧缓冲、着色器等。栅格最多 64 个已解码 256×256 瓦片，导航不再读文件或切换 overview，因此不是 GeoTIFF 全流程测速。不再限制原始要素／顶点数量；本地矢量文件沿用 emap 的 2 GiB 导入上限。GeoJSON 在 Worker 中流式解析为原生 mapshaper dataset。点聚合只影响显示缓存，不修改原始坐标、属性、要素数量；线面不因缩放跳过短边或改写边界。仅剔除完整位于屏幕外（含符号扩张范围）的分块。缓存预算只淘汰屏幕外资源，可见工作集超预算时保留完整精度并显示占用，不回退为粗级几何。原始坐标、属性和 CRS 不修改。诊断绘制开关仅用于定位瓶颈，正式性能应使用“全部”。面三角化仅覆盖有效简单环，复杂自交面仍需后续兼容验证。

本页只加载用户选择的真实数据，不生成规则数据。原有 examples 仍使用 Canvas2D。默认测试页不会加载底图，避免把 MapLibre 的 WebGL 误认为本次渲染后端。
