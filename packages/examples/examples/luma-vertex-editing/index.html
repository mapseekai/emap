操作与精度

单击选择要素，橙色边界来自原始几何；空白处拖动平移、滚轮缩放。“定位选中”便于查看小图斑。切换到“顶点编辑”后拖动白色顶点；点图层可直接拖动被选中的原始点。

拖动时红色线段是预览，松开才提交一次可撤销的编辑。Esc 取消拖动，Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做。闭合环和共享拓扑节点一起移动，共享边的相邻要素也会改变；本示例不拆分共享节点、不插入或删除顶点，也不自动修复自交。

点背景复用已有 PointLod，默认 3 CSS 像素网格保留原始代表点（可关闭），面填充保持原始，背景描边可按 Canvas 屏幕规则过滤；选择查询、橙色边界、白色顶点、编辑命令和选中导出使用原始坐标，不使用化简顶点。编辑后仅重新生成受影响的 全精度分块。首次导入和 几何准备仍可能需要等待。选中导出使用保留源坐标系的 GeoJSON 2008（含 CRS），不会暗中转换到 WGS84。本页是独立 luma 编辑验证，默认 emap 编辑器没有切换。

快照导航复用上一帧，平移可能暂时露出未绘区域，缩放时线宽也暂随快照缩放；停止后按当前屏幕过滤设置重新绘制并恢复样式。这不是几何 LOD，也不是每帧完整重绘。编辑时只缓存已完成的背景，原始选中边界和顶点标记每帧通过 luma 实时绘制，不随背景快照缩放。提交后只刷新受影响缓存；复杂面的重新三角化在 Worker 中完成，期间保留完整旧背景，新缓存就绪后一次替换。

Canvas 屏幕过滤仅用于线与面描边：0.35 CSS px 的 arc 包围盒阈值按初始视图调整，顶点先投影到设备像素再截断至半像素；仅删除连续重复命令，全塌缩路径保留 0.1 设备像素短线。会改变小细节的显示，不是严格全精度显示；原生 dataset、面填充/洞、选择与编辑坐标不变。关闭两项可对照原始 GPU 路径。A/B 原始几何压测不含屏幕过滤和快照；过滤后的暖重绘、准备耗时与快照导航应分别测量。
