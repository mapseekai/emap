操作与精度

单击选择要素，橙色边界来自原始几何；空白处拖动平移、滚轮缩放。“定位选中”便于查看小图斑。切换到“顶点编辑”后拖动白色顶点；点图层可直接拖动被选中的原始点。

拖动时红色线段是预览，松开才提交一次可撤销的编辑。Esc 取消拖动，Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做。闭合环和共享拓扑节点一起移动，共享边的相邻要素也会改变；本示例不拆分共享节点、不插入或删除顶点，也不自动修复自交。

点背景复用已有 PointLod，默认 3 CSS 像素网格保留原始代表点（可关闭），线面背景始终保持全精度；选择查询、橙色边界、白色顶点、编辑命令和选中导出使用原始坐标，不使用化简顶点。编辑后仅重新生成受影响的 全精度分块。首次导入和 几何准备仍可能需要等待。选中导出使用保留源坐标系的 GeoJSON 2008（含 CRS），不会暗中转换到 WGS84。本页是独立 luma 编辑验证，默认 emap 编辑器没有切换。
