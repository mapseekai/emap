支持写法

newField = oldField新增或更新字段
d.name读取当前要素属性对象
$.area读取当前要素内置几何值
$.properties.name通过要素代理读取属性
where: area > 0where 过滤需要返回 true / false
_.round(value, 2)字段名与函数同名时使用 _ 访问上下文函数

$ 是当前要素代理；支持 $.area，不支持 $area 这种变量名写法。

内置字段

id当前要素序号
layer_name当前图层名称
layer图层代理，含 name / type / size / bbox 等
properties当前要素属性对象
d当前要素属性对象别名
partCount当前要素部件数量
isNull当前几何是否为空
bbox / bounds当前要素范围 [xmin, ymin, xmax, ymax]
width / height当前要素范围宽高
length线图层长度
area面图层面积
perimeter面图层周长
compactness面图层紧凑度
planarArea面图层平面面积
originalArea面图层原始面积
innerPct面内点质量比例
centroidX / centroidY面质心坐标
innerX / innerY面内部点坐标
x / y点图层坐标
coordinates点图层坐标数组

内置函数

round(n, d)按小数位四舍五入
sprintf(fmt, ...)格式化字符串
blend(c1, w1, c2, w2)按权重混合颜色
format_dms(value, fmt)十进制度转 DMS 文本
parse_dms(text, fmt)DMS 文本转十进制度
int_median(counts, breaks)按分组计数估算中位数
bboxContainsPoint(x, y)当前要素 bbox 是否包含点
bboxIntersectsRectangle(a,b,c,d)当前要素 bbox 是否与矩形相交
bboxContainsRectangle(a,b,c,d)当前要素 bbox 是否包含矩形
bboxContainedByRectangle(a,b,c,d)当前要素 bbox 是否被矩形包含
layer.field_exists(name)图层是否存在字段
layer.field_type(name)读取字段类型
layer.field_includes(name, value)字段是否包含某个值
