交互 Handler (dragPan / scrollZoom)

加载一个数据文件,然后用上面的开关切换交互

0.3.0 起每个交互都是 map 上一个具名 Handler:map.dragPan / map.scrollZoom,各有 enable() / disable() / isEnabled() / setOptions()。 可单独关滚轮保留拖拽,无需碰私有内部。构造期 new Emap({ scrollZoom:false }) 或 interactive:false(等价于全部禁用)亦可。 skipShiftDrag 为 Phase-1 已知限制:可经 setOptions 存值,运行时生效留待后续阶段。
