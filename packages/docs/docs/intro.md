# emap

emap 是面向浏览器的 TypeScript 地图渲染与编辑引擎，使用 Canvas 呈现 mapshaper 数据结构中的拓扑图层。

它适合需要在前端加载、查看、编辑和导出 GeoJSON、TopoJSON、Shapefile ZIP、GeoParquet 或 GeoArrow 数据的应用。

## 你可以用它做什么

- 在浏览器中渲染点、线、面图层。
- 用统一的 `TopologySource` 加载文件、URL 或内存数据。
- 使用内置控件处理导航、历史记录、选择和编辑。
- 在需要时启用 Web Worker，让较重的数据处理离开主线程。
