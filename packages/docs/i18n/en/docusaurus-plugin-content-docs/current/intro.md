# emap

emap is a browser-first TypeScript map rendering and editing engine that uses Canvas to draw topology layers backed by mapshaper data structures.

It is built for applications that need to load, inspect, edit, and export GeoJSON, TopoJSON, Shapefile ZIP, GeoParquet, or GeoArrow data on the client.

## What you can build with it

- Render point, line, and polygon layers in the browser.
- Load files, URLs, or in-memory data through one `TopologySource` API.
- Use built-in controls for navigation, history, selection, and editing.
- Enable Web Worker processing when heavier data work should leave the main thread.

Continue to the installation guide to create your first emap map.
